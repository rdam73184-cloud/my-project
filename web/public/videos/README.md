این پوشه جای فایل ویدئوی معرفی است.

فایل ویدئو را با نام intro.mp4 اینجا بگذارید و در پنل مدیریت
(تنظیمات سایت ← آدرس ویدئوی معرفی) مقدار /videos/intro.mp4 را وارد کنید.

فایل‌های ویدئویی در git ذخیره نمی‌شوند؛ برای سایت عمومی بهتر است ویدئو را
روی یک میزبان فایل آپلود کنید و لینک مستقیم آن را در پنل مدیریت بنویسید.
